# Esőerdők világa – Interaktív felfedező weboldal

Egy interaktív, modern és teljesen reszponzív weboldal, amely bemutatja az esőerdők lenyűgöző élővilágát, kulcsfontosságú környezeti szerepüket és a fenntarthatóság elengedhetetlen fontosságát.

## A projekt célja
A projekt célja egy olyan oktató és szemléletformáló digitális platform létrehozása, amely valós fejlesztői folyamatokat követve valósul meg. A projekt során a csapat végigmegy a kutatás, tervezés, kódolás és tesztelés fázisain, végül pedig prezentálja a kész terméket.

---

## Fejlesztési szakaszok

### 1. Kutatás & Tartalomkezelés 
*   Hiteles információk összegyűjtése az esőerdők rétegeiről (lombkorona, cserjeszint stb.).
*   A legfontosabb állat- és növényfajok kategorizálása.
*   A környezeti veszélyek (erdőirtás, klímaváltozás) és a fenntarthatósági megoldások feltérképezése.

### 2. Tervezés (Design & UX) 
*   **Drótvázak (Wireframes):** Az oldal elrendezésének megtervezése mobilra és asztali nézetre.
*   **UI Design:** Reszponzív, természetközeli színpaletta (zöldek, földszínek) és modern tipográfia kiválasztása.
*   **Interaktivitás:** Felhasználói élmény (UX) tervezése (pl. kvízek, lenyíló kártyák, animációk).

### 3. Kódolás & Fejlesztés 
*   **HTML5:** Szemantikus és akadálymentes struktúra kialakítása.
*   **CSS3 / SCSS:** Modern elrendezések (Flexbox, CSS Grid), reszponzív töréspontok (Media Queries) és animációk.
*   **JavaScript:** Interaktív elemek (élővilág-szűrő, edukációs kvíz, dinamikus galéria) vezérlése.

### 4. Tesztelés & Optimalizálás 
*   **Cross-browser tesztelés:** Működés ellenőrzése Chrome, Firefox, Safari és Edge böngészőkben.
*   **Reszponzivitás:** Mobil, tablet és desktop kijelzők támogatása.
*   **Teljesítmény:** Képek optimalizálása, betöltési sebesség növelése (Lighthouse teszt).

## Felhasznált technológiák
*   **Frontend:** HTML5, CSS3 / Flexbox / Grid, JavaScript (ES6+)
*   **Verziókezelés:** Git & GitHub

## Helyi futtatás (Telepítés)

1. Klónozd a repozitóriumot:
   ```bash
   git clone https://github.com
   ```
2. Lépj be a projekt mappájába:
   ```bash
   cd esoerdok-vilaga
   ```
3. Nyisd meg az `index.html` fájlt a kedvenc böngésződben, vagy indíts egy helyi szervert (pl. Live Server VS Code-ban).
